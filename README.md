# PocketPi Series (v1 & v2)

Custom Raspberry Pi Zero / Zero 2W portable retro gaming handheld builds featuring 3D-printed enclosures and integrated GPIO controls.




I created the first iteration in November 2024, which featured the base Pi Zero, but it didn't have a speaker, a decently sized battery, or Wi-Fi/BT. The battery was only 1000 mAh and didn't last very long. Additionally, the Pi 0 was not very powerful, so it was limited to 2d nes, SNES, and Game Boy games.

I started the second iteration almost exactly 1 year later, but with a bigger battery (5000 mAh PiSuger battery) and a Pi 0 2w, which was much more powerful and could run slightly newer N64 games, and everything earlier. I also changed the color of the case to distinguish them apart. 

Lastly, just a couple of months after the second iteration, I decided to upgrade some things, including a new battery charger (Adafruit PowerBoost 1000 vs. cheap Amazon TP4056 clone) i also added a small speaker, which is where the Pocketpi currently stands as of today.
